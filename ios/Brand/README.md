# Marquee brand mark

**Concept:** A cinema marquee read as the letter **M** — two facade pillars and a peaked canopy — lit by three hibiscus pink bulbs. Salt grey ground, deep olive structure.

This is intentional Lobby Light identity, not a generic film icon.
