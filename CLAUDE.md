# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Marquee (repo name ShowTracker) is a personal film and TV watch diary with three clients sharing one API:

- `backend-server/` — Express + Mongoose API with JWT auth (deployed on Render, see `render.yaml`)
- `main-folder/` — React 18 web app built with Create React App and Tailwind (deployed on Vercel)
- `ios/` — native SwiftUI app for iOS 26, with a widget extension (`MarqueeWidgets`) and UI tests (`MarqueeUITests`)

## Commands

```bash
# API + web client together (API on :5001, web on :3000)
cd backend-server && npm start

# API only (use this when working on iOS)
cd backend-server && npm run start:api

# Web client (README says use Yarn where you can)
cd main-folder && yarn start | yarn build | yarn test
yarn test -- -t "test name"        # run a single Jest test

# Backend logic tests: plain Node assert scripts, no DB, no framework
node backend-server/scripts/test-stats-calendar.js   # also: npm run test:stats
node backend-server/scripts/test-tv-rewatch.js
node backend-server/scripts/test-film-watch-plays.js
node backend-server/scripts/test-stats-ranges.js

# TV Time import CLI
cd backend-server && npm run import-tvtime

# iOS: the Xcode project is generated by XcodeGen from ios/project.yml
cd ios && xcodegen generate && open Marquee.xcodeproj
```

After adding or removing Swift files, run `xcodegen generate` again. Don't hand-edit `project.pbxproj`.

Port 5001 is used because macOS reserves 5000 for AirPlay Receiver. Env templates: `backend-server/.env.example` (Mongo, JWT, TMDB, OMDb, Google/Apple auth, Resend, CORS) and `ios/.env.example`. A build script copies the iOS `.env` into the app bundle. The web client reads `REACT_APP_API_URL` from `main-folder/.env.development`.

## Architecture

**API (`backend-server/`)**
- `app.js` mounts every router under `/api/...`, with auth under `/users`. Protected routes use `authenticate.verifyUser` (passport-jwt reading a Bearer token). Responses are shaped as `{ success, ... }`.
- `routes/` holds thin HTTP handlers. Domain logic lives in `services/`, for example film watch plays/dedupe, TV tracking, TV rewatch sessions, the TV Time import, and the stats dashboard and calendar.
- Movies and TV have parallel model/route sets: `watch`/`tvwatch`, `favorite`/`favoritefortv`, `moviewatchlist`/`tvwatchlist`. TV progress is spread across `tvShowTracking`, `tvEpisodeWatch`, and the rewatch models (`tvRewatchSession`, `tvRewatchEpisode`). Rewatches are recorded separately so the original watch history stays intact.
- All TMDB access goes through the server: `lib/tmdb.js` is rate-limited and caches in memory and in the `MediaMetaCache` collection, and `routes/tmdb.js` proxies `/api/tmdb/...` for clients. Clients must never embed TMDB keys.
- Stats are cached per user in `UserStatsCache` (`services/statsCache.js`). Any route that changes watch data must call `invalidateUserStats(userId)`. The watch, tvtracking, tvepisodes, tvrewatch, and import routes already do.
- Stats calendar math (weeks, streaks, periods) depends on the user's timezone (`services/statsCalendar.js`).

**Web (`main-folder/src/`)**
- `api/axios.js` is the shared client. It attaches the token from `localStorage` and handles 401s. Routes are defined in `components/MainComponent.js`, and most are wrapped in `ProtectedRoute`. Auth and theme state live in `context/`.

**iOS (`ios/Marquee/`)**
- `Core/` holds networking (`APIClient`, which has a Keychain-stored JWT and clears the session on 401), services and models, plus caches. `DesignSystem/` holds shared UI and theme tokens. `Features/` holds the screens.
- The API base URL comes from `AppConfig`. It can be overridden with the `apiBaseURL` UserDefaults key, for example a LAN IP for a physical device.

## iOS design rules (from `.cursor/rules/marquee-ios.mdc` and `ios/DESIGN.md`)

- The palette is locked ("Lobby Light"): Salt Grey `#E5E5DE`, Deep Olive `#3D3B2E`, Hibiscus Pink `#FF4F8B` (used only for actions such as CTAs, mark, rate, and progress), and Olive Leaf `#5C6B4A`. Dark surfaces are `#1C1B16` and `#2A281F`. Never add a second accent or purple/indigo gradients.
- Liquid Glass goes on chrome only: tab bar, toolbars, sheets, search, FABs. Never use it on posters, list rows, or full-screen backgrounds. Prefer the system `TabView`, `ToolbarItem`, `sheet`, and `searchable`, and group custom glass in `GlassEffectContainer`.
- Use SwiftUI with `@Observable` and async/await. Load posters through the cached, downsampled image path, not raw `AsyncImage` in rails.
- Animate with springs of 100–250ms and respect Reduce Motion. Use SF Pro only. Copy should be a short diary voice.
- Read `ios/DESIGN.md` before UI work.
